# Disco Duck

The playable build of Disco Duck, a 1970s disco reskin of Dance Off on Fortune Engine 2.0.

Play: https://lettuce-create.github.io/disco-duck-play/

This repo holds only the built game. The source is in the private Lettuce-Create/Games repo
(`disco-duck/`); publish with `disco-duck/tools/publish_play.sh`.
